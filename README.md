# OmniServe360

Enterprise Salesforce Customer, Sales & Service Management Platform.

## Project Objective

OmniServe360 is a production-style Salesforce application designed
to demonstrate Salesforce development, integration, automation,
security, asynchronous processing and architecture skills.

## Technology

- Salesforce
- Apex
- SOQL
- SOSL
- LWC
- Flow
- Platform Events
- Change Data Capture
- REST APIs
- Named Credentials
- External Credentials
- Queueable Apex
- Batch Apex
- Scheduled Apex
- Git
- GitHub
- Salesforce CLI
- CI/CD

## Clouds

- Sales Cloud
- Service Cloud

## External Systems

- ERP
- Payment Service
- Notification Service

## Development Approach

Source-driven development using Salesforce DX and Git.
